# SMC Wireless Studio – Releases

Ez a nyilvános repository kizárólag az **SMC Wireless Studio** telepítőinek és frissítési csomagjainak publikálására szolgál.

- Forráskód: privát repositoryban marad.
- Ide csak verziózott Windows x64 MSI-k, SHA-256 ellenőrzőfájlok és release note-ok kerülnek.
- Az alkalmazás beépített frissítője innen ellenőrzi a legújabb stabil kiadást.

A telepítők az alkalmazás saját build- és validációs workflow-jából kerülnek publikálásra.
